Милый-милый мини-сайт для просмотра GitHub-профилей 🌸✨ Вводишь username, а сайтик делает запрос к GitHub API и собирает аккуратную карточку с аватаром, именем, био, статистикой, любимыми языками и свежими репозиториями 🐾💻 Получается такой маленький GitHub-паспорт с нежным вайбом и полезной начинкой, я просто так мило все делаю, потому что я не такая как все другие сайты, я маленькая и беззащитная, но очень старательная 🥺💕

## Как это работает

Ой, приветик! 🌸 Мой сайточек сделан из самых простых и чистых HTML, CSS и Vanilla JavaScript, ничего лишнего, ведь я такая скромная... ✨

Когда кто-то такой милый отправляет форму, мой JavaScript-чик трепетно берёт username, показывает загрузочку (я так волнуюсь! 😳) и шлёт нежные запросы:

- https://api.github.com/users/{username}, чтобы узнать всё о профиле;
- https://api.github.com/users/{username}/repos?per_page=100, чтобы найти репозитории.

После ответа я старательно рисую карточку профиля, считаю языки по репозиториям (хоть и немного путаюсь, но стараюсь! 🥺), сортирую проекты и показываю результат. Если вдруг введут второй username, я всё сделаю заново для второго профиля, и наши карточки будут стоять рядом-рядышком, как маленькие друзья! 💕🐾
